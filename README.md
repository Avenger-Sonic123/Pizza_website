# Pizza Menu Website

A pizza menu page intended to display and extend a list of menu items.

**Repository created:** 2021-06-21  
**Project status:** Learning project / historical snapshot  
**Earliest recorded commit (author date):** 2021-06-21

## Features and implementation

- HTML menu interface.
- Pizza imagery.
- Initial JavaScript menu array and function stubs.

## Technologies

HTML, CSS, JavaScript, Bootstrap, jQuery.

## Project structure

| File | Purpose |
| --- | --- |
| [`index.html`](index.html) | Main page and user interface |
| [`main.js`](main.js) | Project-specific JavaScript |
| [`style.css`](style.css) | Page styling |

Key functions in the source:
- `main.js`: `getmenu()`, `add_item()`, `add_top()`.

## Run or explore locally

```bash
git clone https://github.com/Avenger-Sonic123/Pizza_website.git
cd Pizza_website
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. The local server requires Python 3; browser-based dependencies may also require internet access.

Open the interface to inspect the layout; menu actions are not fully implemented.

## Current status and limitations

Menu rendering, item addition and topping functions contain unfinished placeholders.
